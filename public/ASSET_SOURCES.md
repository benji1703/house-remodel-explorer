# Third-party visual assets

## Poly Haven — CC0

- `textures/herringbone-parquet-*-1k.jpg` and `textures/herringbone-parquet-*-2k.jpg` — [Herringbone Parquet](https://polyhaven.com/a/herringbone_parquet), responsive diffuse, OpenGL normal, roughness and AO maps.
- `models/potted-plant-02/` — [Potted Plant 02](https://polyhaven.com/a/potted_plant_02), 1K glTF package.
- `models/periwinkle-plant/` — [Periwinkle Plant](https://polyhaven.com/a/periwinkle_plant), 1K glTF package.

Poly Haven publishes these assets under [CC0](https://polyhaven.com/license).

## Landscape GLB assets

- `models/landscape/*.glb` — project-authored botanical meshes generated by
  `scripts/build-landscape.py` or the NumPy-compatible `scripts/build-landscape-pure.py`
  fallback when the bundled Blender runtime is unavailable. Each species is exported as a true 3D glTF
  object with connected stems/branches, individually modeled leaves and
  flowers, plus a reduced light profile for mobile. They are design-study
  assets rather than scans of a particular nursery specimen; botanical names
  identify the intended source species.
- `textures/landscape/*.ktx2` — project-prepared PBR bark and gravel maps,
  transcoded to Basis/KTX2 for browser delivery. JPG source maps remain beside
  them for inspection and rebuilds.

## Supplied mood references and original fixture models

- The renderer samples patches from the existing files in `references/moods/`.
  Exact image/crop provenance is in `data/moodSurfaces.ts`; no replacement images
  or third-party material licenses were added by this pass.
- `models/mood/*.glb` — original Blender meshes for the closed D-seat wall-hung
  WC (`mood-ensuite-06.jpeg`) and rolled-lip clay olive pot
  (`mood-terrace-08.jpeg`). These are modeled interpretations, not scans or
  manufacturer CAD. Fixture dimensions are proposed visual sizes.
- `models/landscape/trachelospermum-jasminoides*.glb` — original supported white
  jasmine inspired by `mood-terrace-05.jpeg`, replacing the magenta flowering vine.
- The myrtle, sage and rosemary GLBs were rebuilt with connected low branches and
  leafy mounds using the existing plant-reference images. All of these replacements
  are authored/exported by `scripts/build-mood-fixtures.py` using Blender 4.5 LTS,
  then Meshopt packed with `scripts/pack-mood-fixtures.mjs`. Light/far versions
  reduce leaf/branch counts. No stock photographs were turned into floating cards.
