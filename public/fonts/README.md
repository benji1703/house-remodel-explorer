Figtree (300–900) and Newsreader (200–800, regular and italic) are the existing
Latin variable WOFF2 assets, copied unchanged from the Google Fonts output.
The three files total 142,836 bytes. They are loaded through `next/font/local`
with preloads and metric-adjusted fallbacks. Optional display prevents a late
font swap on a slow connection. Builds no longer need to fetch font CSS.

Original font sources and redistribution licenses:

- [Figtree](https://github.com/google/fonts/tree/main/ofl/figtree) — `figtree-OFL.txt`
- [Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader) — `newsreader-OFL.txt`
